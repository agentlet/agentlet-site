title: Getting started
description: Clone agentlet-core and run the built-in demo.
---

The fastest way to try agentlet is to run the built-in examples from the core repository.

```bash
git clone https://github.com/agentlet/agentlet-core.git
cd agentlet-core
npm install
npm run demo
```

This builds the agentlet-core library, starts a development server on `http://localhost:3000`, and opens your browser to the examples page.
