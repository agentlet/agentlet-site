description: What agentlet is and how it augments existing web applications.
---

Agentlet augments existing web applications with enhanced capabilities including form automation, data extraction, AI integration, and UX improvements, all deployed via lightweight bookmarklets or browser extensions.

This removes the immediate need for backend modifications, complex deployments, or lengthy development cycles, letting teams rapidly enhance user workflows.

Agentlet offers three deployment approaches: bookmarklets for instant deployment, browser extensions for enhanced capabilities, and native integration for applications that can embed the framework directly.
